# 👟 Ghadam-No | Shoe Store Landing Page

A responsive, right-to-left (Persian) landing page for a shoe store, built with **pure HTML and CSS**.
I built this project to practice page layout and to add a sample to my portfolio.

🔗 **Live demo:** [GitHub Pages link]

![Project preview](screenshots/preview.png)

## Page Sections
- Sticky navigation bar with an animated underline on hover
- Hero section with a call-to-action button
- Product cards with hover effects
- About section with store statistics
- Contact form

## Techniques Practiced
- Layout with **Flexbox** (navbar, hero, cards, stats)
- **CSS variables** (`:root`) for a consistent color system
- **Responsive design** using `@media` queries and `clamp()`
- Smooth scrolling with `scroll-behavior` and `scroll-padding-top` to account for the sticky header
- Accessibility: `:focus-visible` styles and `prefers-reduced-motion` support
- Semantic HTML (`header`, `nav`, `main`, `section`, `article`, `footer`)
- Persian language and RTL support (`lang="fa" dir="rtl"`)
